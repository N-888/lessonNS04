### 3. НАСТРОЙКА TELEGRAM В N8N:
- [ ] **Настроить Credential Telegram**
  - В ноде Telegram нажать "Create New Credential"
  - Ввести токен бота
  - Сохранить
  - **Скриншот:** Telegram Credential создан

- [ ] **Настроить Chat ID**
  - В ноде Telegram в поле "Chat ID" ввести свой Chat ID
  - Убедиться, что поле Text содержит Expression:
    ```
    Новая заявка!
    Имя: {{ $json["query"]["name"] }}
    Email: {{ $json["query"]["email"] }}
    Телефон: {{ $json["query"]["phone"] }}
    ```
  - **Скриншот:** Нода Telegram с настроенным текстом

### 5. НАСТРОЙКА AIRTABLE:
- [ ] **Зарегистрироваться в Airtable**
  - https://airtable.com → Sign up for Free
  - Зарегистрироваться через Google или email
  - **Скриншот:** Экран после регистрации

- [ ] **Создать базу данных**
  - "+ Create" → "Build an app on your own"
  - Переименовать базу: "CRM"
  - Переименовать таблицу: "Orders"
  - Удалить лишние поля, оставить Name
  - Добавить поля:
    - email (тип: Email)
    - phone (тип: Phone number)
  - **Скриншот:** Таблица с тремя полями (name, email, phone)

- [ ] **Получить Access Token**
  - Значок аккаунта → Builder hub → Personal access tokens
  - Create Token → добавить ВСЕ scope и ресурсы
  - Скопировать токен (СОХРАНИТЬ СРАЗУ!)
  - **Скриншот:** Созданный токен

- [ ] **Настроить ноду Airtable в n8n**
  - Нажать "+" → найти Airtable → Create a Record
  - Create New Credential → вставить Access Token
  - Base: CRM, Table: Orders
  - Перетащить поля из Webhook:
    - name ← ...query.name
    - email ← ...query.email
    - phone ← ...query.phone
  - **Скриншот:** Нода Airtable с полями

- [ ] **Протестировать**
  - Нажать "Execute Step" для ноды Airtable
  - Проверить запись в Airtable
  - **Скриншот:** Таблица Airtable с новой строкой

### 6. НАСТРОЙКА БИПИУМ (дополнительное задание, 152-ФЗ):
- [ ] **Зарегистрироваться в Бипиум**
  - https://bpium.ru → Создать систему
  - Подтвердить email, заполнить данные
  - **Скриншот:** Экран после входа

- [ ] **Создать каталог**
  - "+ Создать каталог" → "Заказы"
  - Добавить поля: Имя, Почта, Телефон
  - Получить ID: шестерёнка → "Задать ID для API"
  - **Скриншот:** Каталог с полями

- [ ] **Настроить HTTP Request в n8n**
  - "+" → HTTP Request
  - Method: POST
  - URL: `https://<твой-поддомен>.bpium.ru/api/v1/catalogs/<ID>/records`
  - Headers: `Authorization: Basic base64Encode(email:password)`
  - Body → JSON:
    ```json
    {
      "values": {
        "2": "{{ $json['query']['name'] }}",
        "3": "{{ $json['query']['email'] }}",
        "4": "{{ $json['query']['phone'] }}"
      }
    }
    ```
  - **Скриншот:** Нода HTTP Request

- [ ] **Протестировать**
  - Execute Step → проверить Бипиум
  - **Скриншот:** Таблица Бипиум с заявкой
