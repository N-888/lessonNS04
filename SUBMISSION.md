# Домашнее задание NS04

## Webhook → Telegram → Airtable

---

## 1. Описание проекта

Автоматизированная система обработки заявок, принимающая данные через Webhook, отправляющая уведомления в Telegram и сохраняющая записи в Airtable.

### Рабочая схема

```
Webhook ──→ Telegram
   │              │
   └──→ Airtable ←┘
```

- Webhook → Telegram (параллельно)
- Webhook → Airtable (параллельно)
- Telegram → Airtable (дополнительная связь)

---

## 2. Описание нод

| Нода | Тип операции | Описание |
|------|-------------|----------|
| **Webhook** | GET | Принимает заявку с параметрами `name`, `email`, `phone` |
| **Telegram** | sendMessage | Отправляет уведомление в чат бота с данными заявки |
| **Airtable** | create record | Создаёт запись в таблице с полями Name, Email, Phone |

---

## 3. Передача данных (Expressions)

| Нода | Поле | Expression |
|------|------|------------|
| Telegram | text | `Новая заявка!\nИмя: {{ $json.query.name }}\nEmail: {{ $json.query.email }}\nТелефон: {{ $json.query.phone }}` |
| Airtable | Name | `{{ $json.query.name }}` |
| Airtable | Email | `{{ $json.query.email }}` |
| Airtable | Phone | `{{ $json.query.phone }}` |

---

### Установка

1. Клонировать репозиторий:
```bash
git clone https://github.com/N-888/lessonNS04.git
```

2. Импортировать в n8n:
   - Открыть n8n → `http://localhost:5678`
   - Menu (☰) → **Import from File**
   - Выбрать `homework-final.json`

3. Настроить credentials:
   - Telegram Bot Token
   - Airtable Personal Access Token

4. Протестировать:
   - Нажать **Execute workflow**
   - Открыть тестовый URL в браузере

## Заключение

В ходе выполнения домашнего задания NS04 была создана автоматизированная система обработки заявок на основе n8n. Реализована интеграция трёх сервисов: Webhook для приёма данных, Telegram для отправки уведомлений и Airtable для хранения записей.

### Результаты

- Настроен Webhook endpoint для приёма заявок через GET-запрос
- Создан Telegram бот, отправляющий уведомления с данными заявки
- Настроена интеграция с Airtable для автоматического сохранения записей
- Реализована передача данных между нодами с помощью Expressions
- Протестирована рабочая схема: данные поступают на Webhook, распределяются по Telegram и Airtable

### Использованные технологии

- **n8n** — платформа для автоматизации бизнес-процессов
- **Telegram Bot API** — API для создания и управления ботами
- **Airtable** — облачная база данных с табличным интерфейсом
- **Expressions** — механизм передачи данных между нодами n8n

### Заключение

Проект демонстрирует возможность создания простой, но эффективной системы автоматизации обработки заявок без написания кода. Все компоненты работают в связке: Webhook принимает данные, Telegram мгновенно уведомляет ответственного, а Airtable сохраняет структурированные записи для дальнейшей аналитики.
