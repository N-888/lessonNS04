## Как выполнить каждое действие

### 1. Регистрация в n8n Cloud
1. Перейди на https://n8n.cloud
2. Нажми "Get Started" или "Sign Up"
3. Зарегистрируйся через Google или email
4. Активируй аккаунт
5. **Сделай скриншот:** Главный экран n8n после входа

### 2. Создание Telegram бота
1. Открой Telegram
2. Найди @BotFather
3. Отправь команду `/newbot`
4. Следуй инструкциям:
   - Введи имя бота (например: "Мой бот уведомлений")
   - Введи username (должен заканчиваться на "bot")
5. Сохрани токен бота
6. Найди своего бота в Telegram
7. Отправь ему любое сообщение
8. Получи Chat ID:
   - Открой браузер
   - Перейди по адресу: `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   - Найди `"chat":{"id":` - это твой Chat ID
9. **Сделай скриншот:** Сообщение от BotFather с токеном

### 3. Настройка webhook в n8n
1. Открой n8n в браузере
2. Нажми "+" в правой верхней части
3. Выбери "Import from File"
4. Выбери файл `homework-webhook.json`
5. Настрой credential для Telegram:
   - Введи токен бота
   - Сохрани
6. Настрой Chat ID в ноде Telegram
7. Нажми "Active" для активации workflow
8. **Сделай скриншот:** Workflow с тремя нодами

### 4. Тестирование webhook
1. Активируй workflow в n8n
2. Открой браузер
3. Перейди по URL:
   ```
   https://твой-n8n.webhook/new-lead?email=test@example.com&name=Тест&phone=+79991234567
   ```
4. Проверь:
   - Сообщение в Telegram
   - Запись в Airtable
   - Запись в Бипиум (если настроено)
5. **Сделай скриншоты:** Telegram + Airtable + Бипиум

### 5. Настройка Airtable
1. Зарегистрируйся в Airtable
2. Создай базу "CRM" с таблицей "Orders"
3. Добавь поля: name, email, phone
4. Получи Access Token:
   - Нажми на значок аккаунта → "Builder hub"
   - "Personal access tokens" → "Create Token"
   - Добавь все scope и ресурсы
   - Скопируй токен (СОХРАНИ СРАЗУ!)
5. Настрой ноду Airtable в n8n
6. **Сделай скриншот:** Таблица Airtable с данными

### 6. Настройка Бипиум (для 152-ФЗ)
1. Зарегистрируйся в Бипиум
2. Создай каталог "Заказы"
3. Добавь поля: Имя, Почта, Телефон
4. Получи ID каталога (шестерёнка → "Задать ID для API")
5. Настрой ноду HTTP Request в n8n:
   - Method: POST
   - URL: https://твой-поддомен.bpium.ru/api/v1/catalogs/16/records
   - Headers: Authorization: Basic base64Encode(email:password)
   - Body: JSON с полями "2", "3", "4"
6. **Сделай скриншот:** Таблица Бипиум с данными
